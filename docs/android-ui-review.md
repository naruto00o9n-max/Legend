# تجربة Android الحالية

شاشة الترحيب الجديدة فقط أُعيد تصميمها، بالأسود والذهبي، مع هوية كوكيز ورسوم متحركة. المحرر يحتفظ بواجهات وأدوات YTyper الأصلية.

الدخول بالبريد وكلمة المرور **محلي على هذا الجهاز**: يمكن إنشاء ملف وتسجيل الدخول إليه أو الدخول كضيف. لا توجد خدمة تحقق بريد أو استعادة كلمة مرور أو مزامنة. المشاريع تشترك في مساحة الجهاز.

| المجموعة | الفحص الفعلي | حدود النتيجة |
|---|---|---|
| الدخول | إنشاء ملف، رفض كلمة مرور خاطئة، قبول الصحيحة، رفض البريد غير الصحيح والملف المكرر، فحص عدم تخزين كلمة المرور نصًا، مسح الجلسة؛ الدخول من الواجهة والضيف | ملف محلي، دون حساب سحابي |
| الصورة الطويلة | استيراد PNG 800×15000 من مشاركة Android، فتحه من المشروع | صورة اصطناعية معتمة، ليست جميع الصيغ |
| الإيماءات | حقن حركة بإصبعين ومقارنة مصفوفة التكبير؛ تكبير متكرر للوصول إلى عرض قراءة الصفحة | على محاكي Android 30، دون جهاز فعلي |
| النص | إدخال حوار عربي، زيادة الحجم والتحقق من النموذج، تطبيق الحجم والتكبير وعرض الصندوق من إدخالات الواجهة | بعض خصائص النص فقط |
| لوحات النص | الخط والتنسيق واللون والحدود والخلفية والظل والموضع والتباعد و3D والمنظور والتأثيرات والخامة والشفافية والأنماط والممحاة | فُتحت وصُوّرت؛ لم يُفحص كل خيار |
| الرسم | إدخال سلسلة لمس لرسم خط من وضع الرسم الأصلي | ليست جميع أنواع الفرش والممحاة |
| الطبقات والمشاريع | فتح الطبقات ومسودات الصور والأشكال وتغيير الأبعاد والقص؛ التراجع والإعادة؛ حفظ المشروع وإعادة فتح نصوصه العربية | بعض النوافذ فُتحت دون تنفيذ جميع خياراتها |
| التصدير | تنفيذ PNG من استوديو التصدير إلى معرض Android والتحقق من 800×15000 | JPEG وPSD لا يدخلان هذا الفحص |
| محرك الرسم | 39 حالة فعلية، منها الأشكال العشرون والتأثيرات التسعة؛ 235 قياسًا وتنسيقًا للخطوط الأصلية | لا يثبت مطابقة iOS |
| دقة PNG | مقارنة 12 مليون بكسل للصورة الأصلية دون تعديل، وتصدير نص أسفل الصورة وفحص الصفوف غير المعدلة | PNG معتم؛ مسار Android الأصلي يستخدم ذاكرة للصورة كاملة |
| التنظيف | OpenCV الأصلي ينظف حروفًا من صورة 400×400، مع رقعة شفافة خارج القناع وصور قبل/قناع/بعد | فحص حالة واحدة، لا كل سيناريوهات التنظيف |
| المساعد | إدخال حوار وتشغيل الخدمة؛ التحقق من نافذة تطبيق خارجي ونص المساعد فوق الشاشة الرئيسية | بعض شاشات النظام، مثل الإعدادات، تخفي النوافذ العائمة |
| بقية الشاشات | القارئ، الخطوط العربية والإنجليزية والمستوردة، الإعدادات والملف المحلي، محرر الوسوم | يثبت فتح الشاشات لا كل عمليات الاستيراد والإعداد |
| الخدمات | لا يوجد إذن إنترنت؛ Google وDrive والتحديثات والخدمات الأصلية معطلة | المتجر والمجتمع والمنشورات والتنزيل معاينات معطلة |

توقيع APK مفتاح اختبار مؤقت في CI، وقد يختلف عن النسخ السابقة. إن رفض Android تحديث النسخة بسبب التوقيع، صدّر المشاريع قبل إزالة النسخة القديمة. تُحفظ استحقاقات الاشتراكات الأصلية وقد تبقى بعض الميزات المدفوعة مقفلة.

صور الاختبار من محاكي 320×640؛ دقة لقطات الواجهة لا تمثل دقة الصورة المصدرة، التي فُحصت بأبعاد 800×15000. افتح `index.html` بعد فك أرشيف الصور لعرض الواجهات والخطوات والتقرير. الصور فعلية وليست تصاميم مولدة.

تأجّل تطبيق iPhone الكامل بطلب المستخدم. لا يوجد IPA أو محرر iOS كامل، ولا يُسمى أرشيف مكونات Swift/C تطبيقًا جاهزًا. تبقى 105 فروق في 235 حالة تنسيق خطوط، وتبقى الفحوص الصارمة متاحة يدويًا.
